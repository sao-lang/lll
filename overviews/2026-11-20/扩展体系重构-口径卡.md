## 3. 新接口签名（规格 §3 速查）
- `LifecycleBus`（src/hooks/lifecycle.py）：`on(hook, fn)` / `emit(notice)`；异常隔离；同步。
- `Notice`（同上）：frozen；= Invocation 只读投影 + hook 名 + 专属 payload。
- `AOPContainer`（src/aop/container.py）：按角色注册 + 固定顺序编排 + 共用 Registry + 发 `invoke_rejected`。
- `Invocation`/`Next`（src/aop/invocation.py）：Invocation(effect, ctx, session, meta)；Next = Callable[[Invocation], Awaitable[Result]]。
- `Verdict`（同上）：`allowed: bool` + `reason: str`；R9 四态用 `SafetyVerdict`。
- `Prelude/Warden/Envelope/Refiner/Salvage`（src/aop/protocols.py）：run/guard/wrap/refine/recover。
- `Effect = Invoke | Spawn | Suspend | Terminate`（src/runtime/types.py）+ `Disposition` 枚举。
- `Registry`/`PORT_PROTOCOLS`/全部 DTO：保留原位。

AOP 固定顺序：`Prelude → Warden → Envelope(前) → Refiner → Port call → Envelope(后) → Salvage(异常时)`；增强器不声明 priority。

## 4. 16 个 Lifecycle 通知点（最终口径，不得增删）
- 会话/轮次：session_start / user_prompt / session_end / state_fold / budget_check
- 能力调用：before_model / after_model / before_tool / after_tool / tool_error
- 子 Agent：child_spawn / child_done
- 控制流：cancelled / wait_human / resumed
- AOP 拒绝：invoke_rejected
已移除：before_compact / after_compact（P7，R7 内部步骤）/ before_invoke / after_invoke / invoke_error / stop / stop_failure / config_change / file_change。

## 5. Degradation 降级四坑语义（P9 最高风险，必须逐条保留）
1. B1 按 `session_id` 隔离目标状态（Degradation 实例内 `dict[session_id, 状态]`），禁容器级单值。
2. B2 `failed_target` = 降级阶梯里的**后端注册名**（非 ("provider",name) 维度二元组）；网关未注册目标 TargetUnresolved 不静默回退。
3. R3-6 故障目标永久从实例 `available` 剔除**并写回**（非局部副本）。
4. R3-7 retry 耗尽/timeout 的故障记录必须携带 `failed_target`（构造注入 `failed_target_of`）。
决策权集中 Degradation 实例（唯一裁决者）；Warden/Envelope 只报告故障不做选级；先写单测锁四场景再接 Salvage 最后删旧链；端到端降级用例断言不许放水。
