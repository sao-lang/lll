## 快速理解框架（60 秒）

运行时只做一件事：**解释执行 Program 产出的 Effect**。

```
AgentState → Program(用户逻辑, generator) → yield Effect
    → 链路(middleware/hooks/filter/pipes 七挂载点) → Port(外部能力)
    → 结果回填 State → 继续执行 / 挂起 / 结束
```

- M1 决定"循环怎么转"，M2 决定"每一步经过什么"，M3 决定"落到什么实现"。
- 十种内置架构（ReAct / PlanExecute / Supervisor / Graph…）全部是这一循环上的不同脚本。

## 流程纪律

每个模块必须**单独闭环**并通过**门禁**才能合入；违反门禁的模块冻结迭代。详见《门禁体系》。
