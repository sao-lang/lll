## 快速理解框架（60 秒）

运行时只做一件事：**解释执行 Program 产出的 Effect**。扩展由 7 承载形态承载：①组合算子 / ②有状态守卫 / ③call 装饰器 / ④notify 观察 / ⑤Port 接入 / ⑥组件 / ⑦内核机制。旧"三体系正交（Port/AOP/Lifecycle）"口径已被取代：AOP 五角色拆分进②③，LifecycleBus 由④R1 notify 回调取代（16 相位保留为 notify 相位口径）。

```
AgentState → Program(用户逻辑, generator) → yield Effect
    → 组合层 call（③call 装饰器链 retry_call/timeout/danger_route/injection_guard，纯函数组合；②领域策略由 R3 ReliabilityExecutor 显式编排）
    → ⑤Port(外部能力) → 结果回填 State → 继续 / 挂起 / 结束
    ↳ ④R1 notify（16 相位，只读投影，返回值不消费、异常就地隔离）
```

- **R1** 决定"循环怎么转"（核心机制，一行不改），**R2** 是算子核心（①A 类组合算子装配 Program + ②③构造注入 R1 的 call），其余 R3~R7 是经组合层装配接入的能力插件。
- 一切架构（ReAct / PlanExecute / RouterSkill / Graph…）都是这一循环上的 Program 脚本，可任意嵌套。
- **组合式 + 全可插拔**：能力级（用不用）+ 策略级（用什么）+ 实例级（接什么工具）；"算子"仅指①组合算子（Program→Program），retry/timeout/熔断/降级/沙箱/工具/追踪都是能力，不是算子。
- 换实现 = 实现框架协议 + 装配期履约校验；用户不注入时用框架默认实现。
