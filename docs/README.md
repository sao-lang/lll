## 快速理解框架（60 秒）

运行时只做一件事：**解释执行 Program 产出的 Effect**。

```
AgentState → Program(用户逻辑, generator) → yield Effect
    → HookBus 生命周期分发（唯一扩展点，插件返回 Decision）
    → Port(外部能力) → 结果回填 State → 继续 / 挂起 / 结束
```

- **R1** 决定"循环怎么转"，**R2** 决定"每一步经过什么扩展点"，其余 R3~R9 是挂在 Hook 上的能力插件。
- 一切架构（ReAct / PlanExecute / RouterSkill / Graph…）都是这一循环上的 Program 脚本，可任意嵌套。
- **组合式 + 全可插拔**：能力级（用不用）+ 策略级（用什么）+ 实例级（接什么工具），三形态注入（协议替换/Hook/构造参数）。
- 换实现 = 实现框架协议 + 装配期履约校验；用户不注入时用框架默认实现。
