## 快速理解框架（60 秒）

运行时只做一件事：**解释执行 Program 产出的 Effect**。扩展由三体系正交承载：Port（what）/ AOP 增强器（how）/ Lifecycle 通知（when）。

```
AgentState → Program(用户逻辑, generator) → yield Effect
    → AOP 增强器链（how：Prelude→Warden→Envelope→Refiner→Port call→Salvage，Verdict 放行/拒绝）
    → Port(外部能力) → 结果回填 State → 继续 / 挂起 / 结束
    ↳ LifecycleBus（when：16 通知点，Notice 只读投影，返回值不消费、异常就地隔离）
```

- **R1** 决定"循环怎么转"，**R2** 是装配层（AOP 容器 + LifecycleBus），其余 R3~R11 是经 AOP 角色或 Lifecycle 通知接入的能力插件。
- 一切架构（ReAct / PlanExecute / RouterSkill / Graph…）都是这一循环上的 Program 脚本，可任意嵌套。
- **组合式 + 全可插拔**：能力级（用不用）+ 策略级（用什么）+ 实例级（接什么工具），三形态注入（协议替换/AOP 增强器或 Lifecycle 插件/构造参数）。
- 换实现 = 实现框架协议 + 装配期履约校验；用户不注入时用框架默认实现。
