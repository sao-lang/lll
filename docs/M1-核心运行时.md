## 1. 职责与边界

**做**：定义三大原语（State / Effect / Program）；实现解释循环与 Runner；预算强制执行；事件溯源与 checkpoint 挂点。

**不做**：任何具体 IO（不 import LLM SDK / 数据库）；链路实现（M2）；端口实现（M3）。
运行时通过**依赖注入**拿到 M2 的 dispatch 函数与 M3 的 call 函数——测试时注入 fake。

## 2. 完整链路描述

解释器一个 step 的完整时序（伪码）：

```
resume(program, state)
  ├─ 0. 预算预检：budgets 超限？→ 强制 yield Effect("end", reason=BUDGET_EXCEEDED)
  ├─ 1. 驱动 generator：program.send(上次结果) → list[Effect] | Done
  ├─ 2. batch 展开：effect.batch=True → 并行调度，结果按序回填
  ├─ 3. 对每个 Effect：
  │     a. chains.dispatch(eff, ctx)            ← 注入的 M2 函数
  │     b. verdict.allow? → ports.call(eff)     ← 注入的 M3 函数
  │     c. verdict 非 allow → 用 verdict 的替换数据/降级结果作为结果
  ├─ 4. fold(state, effects, results) → 新 State（纯函数，不可变）
  ├─ 5. event_log.append(Event(step, state', effects, results))
  ├─ 6. checkpoint 策略判定（每 N 步 / 挂起时 必存）
  └─ 7. 返回 StepReport；外层 Runner 决定继续 / 挂起 / 结束
```

挂起语义：program yield `Effect("wait_human")` 或 `Effect("end")` 时循环停止；
恢复时从 checkpoint 重建 Session，继续 resume——**这就是跨周期断点恢复**。

## 3. 设计原语

| 原语 | 一句话定义 |
|------|-----------|
| `AgentState` | 会话全部进度，frozen dataclass，任何"修改"都是产生新对象 |
| `Effect` | 对外部世界的声明，6 种 kind 的固定枚举 |
| `Program` | generator：`State → yield Effect* → Done`，必须纯函数 |
| `Budgets` | 全局预算（由运行时强制执行，程序不许自己数） |
| `Event` | 事件溯源的最小单元，append-only |
| `Session` | program + state + event_log + 配置的聚合根 |

## 4. 接口定义与实现

```python
# runtime/types.py —— 原语（全框架的公共类型，M2/M3 只 import 这里）
class EffectKind(str, Enum):
    LLM = "llm"; TOOL = "tool"; CHILD = "child"
    SKILL = "skill"; WAIT_HUMAN = "wait_human"; END = "end"

@dataclass(frozen=True)
class Effect:
    kind: EffectKind
    payload: Mapping[str, Any] = field(default_factory=dict)
    batch: bool = False
    trace_id: str | None = None        # 注入用，解释器自动填

@dataclass(frozen=True)
class Budgets:
    max_turns: int = 30
    max_hops: int = 5                  # Handoff 用
    max_rounds: int = 3                # Reflection 用
    max_cost_usd: float = 5.0
    max_parallel_children: int = 8     # Supervisor 用

@dataclass(frozen=True)
class AgentState:
    messages: tuple[Message, ...] = ()
    scratchpad: Mapping[str, Any] = field(default_factory=dict)
    budgets: Budgets = Budgets()
    version: str = "0.0.0"             # program+prompt 模板版本，进 trace

DONE = object()                        # program 结束哨兵
Program = Generator[Effect, Any, None]  # yield Effect; send() 收结果
```

```python
# runtime/interpreter.py —— 解释器（纯逻辑，无 IO）
class Interpreter(Protocol):
    def resume(self, program: Program, state: AgentState,
               last_results: list[Result]) -> list[Effect] | DONE: ...

class InterpreterImpl:
    """驱动 generator：send(last_results) 收下一批 Effect。
    预算检查在 runner 层做，解释器只保证确定性。"""

# runtime/runner.py —— 执行器（唯一的 async IO 编排点）
class Runner:
    def __init__(self, dispatch: DispatchFn, call: CallFn,
                 store: EventStore | None = None): ...
    async def run(self, session: Session) -> RunResult: ...
    async def step(self, session: Session) -> StepReport: ...   # 单步，供调试/HITL
```

`DispatchFn = Callable[[Effect, ChainCtx], Awaitable[DispatchResult]]`（M2 提供）；
`CallFn = Callable[[Effect, ChainCtx], Awaitable[Result]]`（M3 提供）。

## 5. API 规范

- **命名**：类型 PascalCase；Effect kind 全小写枚举；scratchpad 键名 snake_case。
- **fold 约定**：`fold(state, effects, results) -> AgentState` 是模块唯一的状态变更入口；
  任何直接改 messages/scratchpad 的写法都禁止（frozen 保证）。
- **错误分类**（框架级异常，进 StepReport 而非抛穿）：
  `BudgetExceeded` / `ProgramInvalid`（yield 了非法对象）/ `PortMissing`（运行时 port 未注册）/ `ProgramCrashed`。
- **确定性约定**：同一 State + 同一事件日志 → 同一批 Effect。Program 内禁止 `datetime.now()`、
  随机数、直接网络调用；需要随机性/时间由 payload 声明，由外壳注入。

**最小用法示例**（P0 验收脚本）：

```python
def react_program(state: AgentState):
    while True:
        resp = yield Effect(EffectKind.LLM, {"messages": state.messages})
        if not resp.tool_calls:
            yield Effect(EffectKind.END, {"output": resp.content}); return
        state = fold_tool_calls(state, resp.tool_calls)
        results = yield Effect(EffectKind.TOOL, {"calls": resp.tool_calls}, batch=True)
        state = fold_tool_results(state, results)

runner = Runner(dispatch=fake_dispatch, call=fake_call)
report = await runner.run(Session(program=react_program, state=AgentState(...)))
```

## 6. 关键字段

**AgentState**：

| 字段 | 类型 | 说明 |
|------|------|------|
| messages | tuple[Message] | 对话历史，只增不减（裁剪是视图层的事） |
| scratchpad | Mapping[str, Any] | 黑板：`phase` / `steps` / `cursor` / `hops` / 跨架构中间产物 |
| budgets | Budgets | 本会话预算，每 fold 由 runner 扣减 |
| version | str | program + prompt 模板版本号，回放对齐用 |

**Event**（事件溯源）：

| 字段 | 类型 | 说明 |
|------|------|------|
| seq | int | 单调递增序号 |
| session_id | str | 会话标识 |
| step | int | 第几个 step |
| state_snapshot | AgentState | fold 后的完整状态 |
| effects / results | list | 本步的声明与结果 |
| ts / cost_usd / token | 标量 | 审计与预算扣减依据 |

## 7. 依赖关系

- **依赖**：无（types 自包含）；`dispatch`/`call` 为注入函数签名。
- **被依赖**：M2/M3 及后续全部模块 import `runtime/types.py`。

## 8. 验收标准与门禁

**验收标准**（= 门禁 G3 的行为用例来源）：

1. 用 fake dispatch/call 跑通 ReAct program 全流程；
2. 同输入两次 run，事件日志逐字节一致；
3. 预算超限强制 END；
4. `wait_human` 挂起 → 从 checkpoint 恢复 → 继续执行。

**门禁清单**（制度见[《门禁体系》](./门禁体系.md)，下表为 M1 专属，逐条硬性）：

| 门禁 | 条目 | 达标标准 | 级别 |
|------|------|---------|------|
| M1-G1 | 覆盖率 | interpreter / fold / budget 单测覆盖率 ≥ 90%，mypy strict 通过 | G1 |
| M1-G2 | 确定性 | 同输入两次 run，事件日志哈希逐字节一致（CI 自动比对） | G2 |
| M1-G2 | 回放 | 从事件日志重放恢复的 State 与终态 State 全等 | G2 |
| M1-G2 | 预算 | 5 类预算（turns/hops/rounds/cost/parallel）各有超限强制 END 用例 | G2 |
| M1-G3 | 集成 | 用 fake dispatch/call 跑通 ReAct 全流程；wait_human 挂起→checkpoint 恢复→续跑 | G3 |
| M1-红线 | 纯函数 | Program 内出现 `datetime.now()` / `random` / 网络调用 → **AST 扫描拒绝合入** | 红线 |

**闭环核对**（五条件定义见门禁体系）：契约自足 ✓ / 自带 fake ✓（fake_dispatch/fake_call）/
自带测试 ✓（tests/runtime/）/ 独立 demo ✓（`make demo-m1`）/ 文档自足 ✓（本文档）。
