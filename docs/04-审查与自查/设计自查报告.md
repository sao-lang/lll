5. 四组 API 完整定义补进 R11。

## 三、根因

整合重构时把"能力详设（H0~H10）"与"模块实现详设（R1~R11）"合并，采用了**每模块 10 节固定模板**，导致：
- 不在 10 节模板里的横切内容（三层插拔、协议全集、能力全景、组合算子）被丢弃；
- 深度参数/算法/状态机被压缩成"核心字段表 + 门禁表"。

**修正原则**：横切契约独立成模块详设（R12/R13），能力全景独立成总览文档；深度细节回填到对应 R 文档。
