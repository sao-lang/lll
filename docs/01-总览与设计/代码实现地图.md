## 2. 做完的模块看哪些代码

每个模块都从 `__init__.py` 入手——它列出该模块的公共 API（`__all__`）。

### M1 核心运行时 · `src/runtime/`

| 文件 | 职责 | 建议顺序 |
|------|------|----------|
| `__init__.py` | 公共 API 清单 | ① 先看 |
| `types.py` | State / Effect / Event / Budgets / Program 数据模型，确定性基础 | ② 核心 |
| `interpreter.py` | Effect 解释循环（`Interpreter` / `EffectBatch`） | ③ 核心 |
| `runner.py` | `Runner`、事件存储、checkpoint / 恢复 | ④ |
| `fold.py` | 状态折叠、事件回放、工具调用回填 | ⑤ |
| `errors.py` | 异常体系（预算超限 / 程序崩溃 / 端口缺失…） | ⑥ |

配套：`tests/m1/`（8 个用例文件）、`demos/demo_m1.py`。

### M2 链路系统 · `src/chains/`

| 文件 | 职责 | 建议顺序 |
|------|------|----------|
| `__init__.py` | 公共 API 清单 | ① |
| `types.py` | 七挂载点 `MountPoint`、`Verdict`、`ChainCtx` | ② 核心 |
| `chains.py` | `Chains` 主体、dispatch 装配、四泳道 | ③ 核心 |
| `builtins.py` | 内置 middleware / hook / filter / pipe 组件 | ④ |

配套：`tests/m2/`（5 个）、`demos/demo_m2.py`。

### M3 端口协议层 · `src/ports/`

| 文件 | 职责 | 建议顺序 |
|------|------|----------|
| `__init__.py` | 公共 API 清单（12 个 Port 协议 + DTO） | ① |
| `protocols.py` | 各 Port 的 Protocol 契约（LLM/Tool/RAG/Memory/Store…） | ② 核心 |
| `dto.py` | 统一 DTO：`LLMRequest` / `ToolCall` / `ToolResult`… | ③ |
| `registry.py` | `PortRegistry` 注册表、契约校验 | ④ |
| `call.py` | call 折叠、异常分类与错误信封 | ⑤ |
| `adapters/` | 默认适配器：`llm.py` / `tools.py` / `human.py` / `telemetry.py` / `fakes.py` | ⑥ |

配套：`tests/m3/`（5 个）、`demos/demo_m3.py`。

### M4 工具系统 · `src/harness/tools/`

| 文件 | 职责 | 建议顺序 |
|------|------|----------|
| `__init__.py` | 公共 API 清单 | ① |
| `decorator.py` | `@tool(pydantic)` 装饰器、`ToolDefinition`、schema | ② 核心 |
| `registry.py` | `ToolRegistry`、danger 分级路由、静态检查 | ③ 核心 |
| `index.py` | `ToolIndex` 渐进式披露（按需加载 schema） | ④ |
| `mcp.py` | `MCPManager` / `MCPTransport` 外部工具接入 | ⑤ |
| `fakes.py` | 测试用假依赖（沙盒 / 审批 / MCP 传输） | ⑥ |

配套：`tests/m4/`（5 个）、`demos/demo_m4.py`。

## 3. 全局入口与共用件

| 位置 | 作用 |
|------|------|
| `tests/conftest.py` | 把 `src/` 加入 `sys.path`，仓库根可直接跑 pytest（无需先安装） |
| `tests/fakes.py` | 跨模块共用的假依赖 |
| `tools/gate_check.py` | 门禁执行器（G0~G4），模块配置里的 `pkg` 为顶层包名、`doc` 指向本目录文档 |
| `tools/ast_scan.py` | 红线静态扫描（AST），按模块检查纯函数 / 留名 / 无状态 / MCP 全量注入 |
| `Makefile` | `make test` / `demo-mX` / `gate-mX` 统一入口 |
| `pyproject.toml` | 依赖、coverage source（四个顶层包）、pytest 配置 |
